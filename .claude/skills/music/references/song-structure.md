# Song structure & lyric craft

## Section tags

Both Suno and ACE-Step read bracketed section tags to understand the
arrangement. Use them on their own line, above the lines they govern.

| Tag | Use |
| --- | --- |
| `[Intro]` | Opening — often instrumental or atmospheric, sets the tone |
| `[Verse]` / `[Verse 1]` / `[Verse 2]` | Story / detail; lower energy than chorus |
| `[Pre-Chorus]` | Build / lift into the chorus |
| `[Chorus]` | The hook — highest energy, most memorable, repeated |
| `[Post-Chorus]` | Tag/echo after the chorus, optional |
| `[Bridge]` | Contrast section — new chords/melody, the "turn" |
| `[Instrumental]` / `[Solo]` | No vocals; name the lead instrument, e.g. `[Guitar Solo]` |
| `[Hook]` | Short repeated catchphrase |
| `[Outro]` | Ending — fade, reprise, or resolve |
| `[Break]` | Drop / silence / beat break |

Inline performance cues also help: `(whisper)`, `(ad-lib)`, `(harmony)`,
`(spoken)`, `(build up)`, `(drop)`.

## Reliable arrangement patterns

Pick one to fit the length/energy. Aim for a clear chorus payoff.

- **Pop standard (~3:00):** Intro → Verse 1 → Pre-Chorus → Chorus → Verse 2 →
  Pre-Chorus → Chorus → Bridge → Chorus → Outro
- **Short / punchy (~2:00):** Intro → Verse → Chorus → Verse → Chorus → Outro
- **Dance / EDM:** Intro → Build → Drop (Chorus) → Verse → Build → Drop →
  Breakdown → Drop → Outro
- **Ballad:** Intro → Verse → Chorus → Verse → Chorus → Bridge → Final Chorus
  (key change optional) → Outro

## Lyric craft checklist

- **Concrete over abstract.** Specific images ("濡れたアスファルト、終電のドア")
  beat vague feelings ("悲しい気持ち").
- **One idea per section.** Verses advance the story; the chorus states the
  emotional core.
- **The chorus must be singable and repeatable.** Short lines, strong vowels,
  a title-bearing hook line.
- **Contrast in the bridge.** Shift perspective, time, or mood — don't just
  repeat a verse.
- **Match syllables to tempo.** Fast BPM → fewer syllables per line; ballad →
  room to breathe.
- **Keep one language unless asked.** Mixed JP/EN is fine *if* intentional
  (common in city pop / J-pop hooks) — flag it as a choice, not an accident.
- **Avoid clichés and forced rhymes.** A near-rhyme that means something beats
  a perfect rhyme that doesn't.

## Length guidance

State an approximate runtime in the spec. Suno/ACE-Step generate to a target
duration, so 2–4 minutes is the sweet spot. More sections ≈ longer track.
